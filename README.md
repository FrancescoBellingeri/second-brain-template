# Second Brain Template

Personal memory system + content automation for developers.
Stack: Graphify (graph memory) · Claude Code (capture) · agency-agents (content production)

## Structure

| Folder | Purpose |
|--------|---------|
| `inbox/` | Raw unprocessed notes |
| `permanent/` | Stable, reusable knowledge |
| `projects/` | One folder per active project |
| `clips/` | Content saved from external sources |
| `templates/` | Frontmatter templates for each note type |
| `commands/` | Custom slash commands for Claude Code |
